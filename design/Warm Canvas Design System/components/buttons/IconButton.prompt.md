Circular 36px icon button — carousel arrows, close, share.

```jsx
<IconButton label="Next" tone="cream"><ChevronRight /></IconButton>
<IconButton label="Dismiss" tone="dark">✕</IconButton>
```

Tones: `cream` (canvas + hairline), `dark` (on navy cards), `bare`. Size defaults to 36 — the system's documented exception to the 44px touch minimum.
